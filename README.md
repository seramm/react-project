# Task manager

## Installation:

Network connection is needed!

```
$ npm install
```

## Running instructions:

For non production usage `$ npm run dev` should be enough. However other alternative could be building the website(`$ npm run build`) and running a server (`$ npx serve -s dist`). The final resuilt is the same so `$ npm run dev` should be enough.

Usually Vite will run on port `5173`. Opening in the browser `http://localhost:5173` should make the page available.
